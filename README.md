# java-db-docs

java-db 使用文档：Db、Row、ActiveRecord、事务、SQL 模板与多数据源。

- 文档站：https://java-db.io.nexus/
- 项目源码：https://github.com/litongjava/java-db
- 拆分自 [tio-boot-docs](https://github.com/litongjava/tio-boot-docs)

## 本地开发

```bash
pnpm install
pnpm docs:dev
```

## 构建

```bash
pnpm docs:check
pnpm docs:build
```

构建产物位于 `docs/.vuepress/dist`。
